# 合成离线例子

[English](README.md) | [简体中文](README.zh-CN.md)

**全部材料均为编造。** 七份短报告、八条检索记录、请求、模拟 AI 回答和模拟人工裁决只用于演示。没有真实论文、被试、作者数据、DOI、API 回答或密钥。标为 AI2／AI3 的记录是人工编写的角色 fixture，不是相应模型的实测表现。

## 一条命令

从 RAES 根目录、用 Python 3.10+ 运行：

```sh
python examples/synthetic/reproduce.py
```

先核验 `FROZEN_INPUTS.json`，再从保存的回答重建流程与效应量，对照 `expected/results.json`：文字、ID、类别及整数精确一致，浮点数允许绝对/相对 `1e-12` 误差。输出到仓库之外的新临时目录，再核验输出哈希；`runtime.json` 单独记录系统和解释器。

也可指定 `--output /path/to/new-directory`，已有目录不会覆盖。不需要安装依赖或调用 API。运行期间有 Python socket 禁用检查，但它不是能够防御不可信程序的操作系统沙箱。

## 这个例子特意包含什么？

REC003 是重复检索记录；SYN001 的 preprint 和 journal 属于同一研究，只纳入一次。SYN005 是 narrative review，SYN004 研究儿童。SYN006 使用 step cards，满足 codebook 的反馈定义，但狭窄关键词筛选漏掉它；两位审计者有分歧，第三位与受限人工裁决支持重新纳入。

SYN001 的模拟编码者把 SE 1.58 写成 SD；AI2 提出具体坐标纠正，AI3 看不到 AI2 建议，独立得到 SD 10.0。SYN002 有一次格式不完整的回答，保留原记录后按相同请求重试。SYN003 缺 SD，研究和两条 arm 行仍保留，效应量明确不计算。

数量为：8 条检索记录 → 去重后 7 条 → 6 份全文 → 5 份纳入报告 → 4 项研究 → 8 条 arm 行。3 个可计算比较对应 6 条 pre-g 审计行和 3 个效应量；1 个比较保留为不可计算。14 个逻辑请求有 15 次尝试。1 条筛选遗漏被找回，1 项编码错误被确认纠正。

效应约为 0.495177、0.443659、0.393717；第二项由 log odds ratio 转换，其余用 pooled SD。这里**不合并这些效应量**，也不据此作任何研究结论。[数值说明](NUMERICAL_METHODS.md) 列出公式及适用范围。

## 与完整流程的对应

S0 提供填好的小 codebook。S1 使用模拟检索快照，不真实检索。S2 做 exact-key 去重，不自动操作 EndNote。S3 是题目规则，TA 审计只看题目/摘要。S4 读取虚构文件的显式字段，不是通用 PDF 解析器。S5 对这个极小排除集合做全查，而非照搬真实项目的抽样停止规则。S6 使用材料上已标明的 Study-ID，不提供通用相似度判重。S7 不需要，因为可用统计量都在文字里。

S8 回放逐篇编码并核查字段、类型、行号和引文。S9 审计可计算的 pre-g 行，缺统计量行仍在编码表中，但不属于这次审计范围。S10 只读查行编号、分开保存纠错、由代码计算效应。S11 做数量和算术核对，不做元回归、出版偏倚或 power。S12 冻结、核验并在新目录重建。

## 去哪里看过程？

`inputs/requests.jsonl` 保存完整结构化请求和哈希，`responses.jsonl` 保存包括失败在内的模拟原始回答。AI2／AI3 用同一份审计 codebook；AI3 只得到原目标、坐标和来源，不得到 AI2 的建议或理由。

输出同时保存原编码、纠错后编码、纠错记录、不可计算理由、未解决项、report-study 对应、审计和尝试日志，以及效应量。行号与引文匹配只能验证“引文确实在那里”，不能保证语义读对；SE／SD 的例子专门说明这一区别。

冻结清单覆盖输入、规则、预期输出和计算代码，也检测输入目录的新增文件。哈希不证明资料正确、真实或在观察结果之前冻结；修改需新版本和说明。成功回放说明软件对这些已知材料按预期运行，不证明真实 AI 的准确率、独立性或跨领域有效性。
