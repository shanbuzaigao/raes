# Questions to ask only when unanswered

## Round 1: what is the synthesis for?
What question does the review answer? What is a study, a record and one coded row?
Which units are independent? What downstream use requires each proposed field?
Avoid demanding an effect size for a narrative review or a clinical PICO for every domain.

## Round 2: what is eligible?
Ask for exact numbered criteria and mixed-condition handling. Separate eligibility
from computability: a missing SD need not remove an otherwise eligible study.
Ask how inaccessible full texts are tracked. Do not turn uncertainty into exclusion.

## Round 3: what is measured?
For each canonical outcome ask its definition, direction, scale and denominator;
which source-specific labels map to it; what clearly does not count. Distinguish SD
from SE, events from totals, arms from comparisons, and subjects from repeated rows.

## Round 4: what can the coder read?
Specify source precedence, allowed supplements and source locators. Identify shared
entity attributes and exact-key cache rules when relevant. If sources conflict,
write a general priority/escalation rule before resolving individual cases.

## Round 5: what should code do?
Separate extracted values and recorded path choices from deterministic conversions,
row identifiers, effect sizes and statistics. Specify treatment/comparator pairing,
shared samples and aggregation. Do not select a statistical model on behalf of the
researcher without flagging it as a proposal.

## Round 6: what must the audit not see?
Screening reviewers need no original decision or reason. Targeted coding auditors
need frozen target coordinates/values, but not original reasoning or downstream
estimates. AI3 uses the SAME audit codebook as AI2, with a different task mode; it
must not see the proposed correction or rationale. Identify permitted human cases.

## Round 7: how will we know the rules are usable?
Choose a small pilot with positive, negative, missing and mixed/boundary cases.
Record timing and changes. Ask for explicit approval before a formal freeze. Do not
interpret three successful synthetic cases as empirical validation of the workflow.
